      Pick how each vote goes and run the whole story. A poll left on no votes resolves through its default — the path that is hardest to rehearse and worst to get wrong live.

      Open a project to see what the show needs and what has been made. The list comes from the scenario itself — an asset appears here because something in the story asks for it, which is why it can never drift out of date.

      The storyboard lives in the project, beside the scenario it describes. It is where the work starts — shots, prompts and spoken lines in one document — and the asset rows are seeded from it. Seeding only ever adds: once a prompt has been tuned here, the document that suggested it does not overwrite it.
